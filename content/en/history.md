Galette was born from a very practical need: an association in Lyon, France, looking for a way to manage its members. More than twenty years later, here is how it got there.

## Key milestones

{{< timeline >}}
{{< timeline-item date="2000 – 2001" >}}
[ALDIL](https://www.aldil.org/), the Lyon LUG, is looking for a membership management tool. Nothing fits, neither PhpLugMembers nor the other tools tried: its president, Loïs (aka GruiicK), calls for volunteers on the association's lists. A first project, GAELLE, quickly dies out: the code is too complex, and the developers too rarely around.
{{< /timeline-item >}}
{{< timeline-item date="2003" >}}
Frédéric (aka Deelight) starts from scratch with a nice, unpretentious application that, in his own words, “does what it's asked to do”. The [founding email](#the-founding-email) goes out on November 21st.
{{< /timeline-item >}}
{{< timeline-item date="2004 – 2005" >}}
The project settles at Gna! (SVN repository, mailing lists, tickets), then at [TuxFamily](https://tuxfamily.org) (website and downloads). The first “stable” version is probably 0.37b; developers, translators, reviewers and testers join in.
{{< /timeline-item >}}
{{< timeline-item date="2007" >}}
Johan (aka trashy) joins the project. A few months later, Loïs hands him the “keys of the truck”: he has been the maintainer ever since.
{{< /timeline-item >}}
{{< timeline-item date="2012" >}}
The source code moves to Git, and the repositories to TuxFamily. The Gna! tracker is abandoned.
{{< /timeline-item >}}
{{< timeline-item date="2017" >}}
Gna! shuts down: the mailing lists move to TuxFamily as well.
{{< /timeline-item >}}
{{< timeline-item date="2024" >}}
[TuxFamily is slowly fading away](https://forum.tuxfamily.org/post/3396/): all project services move to other providers. Thank you TuxFamily for all these years!
{{< /timeline-item >}}
{{< /timeline >}}
