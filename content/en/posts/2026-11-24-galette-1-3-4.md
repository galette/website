A new batch is out of the oven: here is Galette 1.3.4! Mostly fixes, some of them security related. **Upgrading is recommended.**

## On the menu {#on-the-menu-1-3-4}

* Security related fixes
* Two-factor authentication is no longer experimental
* PHP 8.6 support
* Dynamic fields files removed along with their member, contribution or transaction
* Downloading documents with an uppercase extension
* Saved searches labels
* New plugin releases detection
* Fewer database queries
* ...

## Telemetry {#telemetry-1-3-4}

If you chose to send it, telemetry was no longer sent after installation; this is fixed. It now also tells which features are used, the installation mode, and gives more reliable server information. It remains anonymous: only yes/no answers, known values and orders of magnitude.

## Before upgrading {#before-upgrading-1-3-4}

There is no database change in this release, and 1.3 plugins remain compatible. As always, **backup your database** before upgrading!

See [Galette 1.3.4 changelog](https://doc.galette.eu/en/master/changelog.html#v1340) for all details.
