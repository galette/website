After a year of work and more than 650 commits, I'm really happy to announce the release of Galette 1.3.0!

This is the richest release since 1.0: a lot of security, tools to better master your instance, a big accessibility effort, and, as always, a nice list of fixes. Let's have a quick tour.

## Better protected logins

Galette now offers **two-factor authentication**: on top of their password, each member can ask for a one-time code generated by an application such as FreeOTP, Aegis or KeePassXC. Recovery codes are provided when enrolling, and administrators can reset the second factor of a member who lost their phone.

{{< img_link path="/site/assets/images/screenshots/1.3.0/two-factor-enrol-en.png" alt="Enabling two-factor authentication: QR code and key to type in by hand" >}}

This feature is **experimental** and disabled by default: enable it from the security settings, give it a try, and let us know how it goes!

Failed login attempts are now counted, per account and per address, and further attempts are refused for a while. The same goes for password recovery requests and self subscriptions. A new page shows what is being refused, and lets you lift it if needed:

{{< img_link path="/site/assets/images/screenshots/1.3.0/auth-attempts-en.png" alt="Refused authentication attempts page" >}}

Under the hood, CSRF protection now relies on HTTP headers, the session cookie is flagged SameSite, and everything that is typed in and later rendered as is (mailings, PDF models, email texts, dynamic fields…) is sanitized when it is stored.

## Mailings sent in batches

Hosting providers often limit how many emails can be sent per hour or per day. Galette can now **send mailings in batches**, with a delay between two messages and hourly and daily quotas; sending goes through a queue that can be resumed, from the interface, a cron script or the console. Reminders use it as well. This one is also **experimental**, and default values keep the previous behavior.

{{< img_link path="/site/assets/images/screenshots/1.3.0/advanced-config-mail-en.png" alt="Batch sending settings in the advanced configuration" >}}

## An advanced configuration page

A new page lists **every preference** of your instance, including those no form displays: for each one, you can tell whether it holds its default value, has been modified or is locked by `behavior.inc.php`. A few settings moved there from that file (instance URL, session duration…), as well as the maximum size of uploaded files, which can now be set per kind of file:

{{< img_link path="/site/assets/images/screenshots/1.3.0/advanced-config-upload-en.png" alt="Maximum upload sizes in the advanced configuration" >}}

## More independent plugins

Plugins now have their own database version, and are updated on their own. The plugins page has been reworked: it also lists disabled, not installed and outdated plugins. Plugins can declare their own preferences, and public pages with their own visibility.

{{< img_link path="/site/assets/images/screenshots/1.3.0/plugins-en.png" alt="New plugins page" >}}

## Accessibility and comfort

A big effort has been made on accessibility (contrasts, page titles, buttons, keyboard navigation), with automated checks to prevent regressions. The dashboard loads news in the background and no longer hangs, and the language selector handles regional variants:

{{< img_link path="/site/assets/images/screenshots/1.3.0/language-en.png" alt="Language selector with regional variants" >}}

## And also…

* Dynamic fields on preferences; repeatable choice, date and file fields; up to 10 dynamic fields in CSV import
* Filters and pagination on documents list
* Description on contribution types
* Email settings can be tested before being saved, with a connection check
* The adaptive PDF member card is now the default one
* New `galette:superadmin:password` command; super administrator credentials moved to "My information"
* Install and update are guarded by a lock file
* Fixes on membership dates calculation (last valid day, leap years, beginning of membership date)
* Groups managers can edit their own record, and get receipts and invoices of their members
* Customized PDF models and email texts are no longer reset on update
* New Slovenian (complete) and Brazilian Portuguese (started) translations; Russian is almost complete, German and Tamil are complete again
* ...

## Before upgrading

* PHP 8.3 is now the minimum required version; the `fileinfo` PHP module is required, as well as JavaScript in the browser
* QMAIL and Gmail mail methods have been removed: instances using them are switched to sendmail and SMTP respectively
* Plugins compatible with 1.2 are disabled: install their new version at the same time
* Database schema has changed, do not forget to **backup your database** before upgrading!

See [Galette 1.3.0 changelog](https://doc.galette.eu/en/develop/changelog.html#v1300) for all details.

**All** plugins have been updated as well: install them along with Galette, see [plugins documentation](https://doc.galette.eu/en/develop/plugins/) ;-)
