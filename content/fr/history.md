Galette est né d'un besoin très concret : celui d'une association de Lyon qui cherchait comment gérer ses adhérents. Plus de vingt ans plus tard, voici le chemin parcouru.

## Les grandes étapes

{{< timeline >}}
{{< timeline-item date="2000 – 2001" >}}
L'[ALDIL](https://www.aldil.org/), le GULL de Lyon, cherche un outil de gestion des adhérents. Rien ne convient, ni PhpLugMembers ni les autres outils testés : son président, Loïs (alias GruiicK), lance un appel sur les listes de l'association. Un premier projet, GAELLE, s'éteint rapidement : un code trop compliqué, et des développeurs trop peu disponibles.
{{< /timeline-item >}}
{{< timeline-item date="2003" >}}
Frédéric (alias Deelight) repart de zéro avec une application jolie et sans prétention qui, selon ses mots, « fait ce qu'on lui demande ». Le [mail fondateur](#le-mail-fondateur) part le 21 novembre.
{{< /timeline-item >}}
{{< timeline-item date="2004 – 2005" >}}
Le projet s'installe chez Gna! (dépôt SVN, listes, tickets) puis chez [TuxFamily](https://tuxfamily.org) (site et téléchargements). La première version « stable » est probablement la 0.37b ; développeurs, traducteurs, relecteurs et testeurs rejoignent l'aventure.
{{< /timeline-item >}}
{{< timeline-item date="2007" >}}
Johan (alias trashy) rejoint le projet. Quelques mois plus tard, Loïs lui confie les « clefs du camion » : il en est le mainteneur depuis.
{{< /timeline-item >}}
{{< timeline-item date="2012" >}}
Le code source passe à Git, et les dépôts déménagent chez TuxFamily. Le gestionnaire de tickets de Gna! est abandonné.
{{< /timeline-item >}}
{{< timeline-item date="2017" >}}
Gna! ferme ses portes : les listes de diffusion rejoignent elles aussi TuxFamily.
{{< /timeline-item >}}
{{< timeline-item date="2024" >}}
[TuxFamily s'éteint doucement](https://forum.tuxfamily.org/post/3396/) : tous les services du projet déménagent chez d'autres hébergeurs. Merci TuxFamily pour toutes ces années !
{{< /timeline-item >}}
{{< /timeline >}}
